# Maron UI 🌰

## Local Environment

1. pnpm install

```bash
# macOS or Linux
$ curl -fsSL https://get.pnpm.io/install.sh | sh -

# Windows (PowerShell) 
$ iwr https://get.pnpm.io/install.ps1 -useb | iex
```

or

```bash
npm install -g pnpm
```

2. start storybook


```bash
npm run storybook
```

3. open <http://localhost:6006>
